# Application Modules

The V1 application is organized into four primary modules:

- `system_check/` — system detection and readiness checks
- `optimizer/` — curated and reversible configuration changes
- `demo_analyzer/` — CS2 demo parsing and analysis
- `tactical_replay/` — scene reconstruction and analysis replay

Code from legacy prototypes is only moved here after review and classification as **keep** or **revise**.
