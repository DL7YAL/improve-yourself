# Optimizer Overview — Screen Specification

## Authority

**SUPERSEDED:** `optimizer_overview_MASTER.png` has no implementation or
acceptance authority. Canva design `DAHUBn5D2aM`, revision 25, page 6 is the
binding Optimizer visual source.
This specification records the approved Figma export; it does not replace the
PNG and must not be used to invent omitted visual details.

## Fixed visible composition

- Full-height dark application shell with left navigation, top context bar,
  central overview workspace, and a fixed right `DETAILS & ERKLÄRUNG` panel.
- Left shell: stacked `IMPROVE / YOURSELF` wordmark, version marker, primary
  navigation, a selected Optimizer row, secondary navigation, and lower
  system-ready state.
- Top bar: screen title `Optimizer`, four compact hardware chips, overflow
  action, and close action.
- Main overview: recommendation summary card above a two-by-two grid of
  System, Graphics, Network, and BIOS Optimizer cards, followed by the last
  optimization-run card.
- Right panel remains visible with its close action, selected-setting detail,
  status pills, explanatory sections, evidence, recovery, next-step content,
  and a local continuation area.

## Visual constraints

- Preserve the Master’s midnight surfaces, near-black subtle separators,
  restrained cyan/blue interaction language, card edge treatment, hierarchy,
  typography, spacing, and proportions.
- Selected and hover interaction use the Master’s blue treatment. Green,
  amber, and red/orange are semantic status colors only.
- Do not introduce a global page scrollbar. Any overflow belongs only to its
  corresponding local content region.
- The Master’s example system facts, counts, recommendations, and dates are
  visual examples, not product data.
