# System Optimizer Detail — Screen Specification

## Authority

`system_optimizer_detail_MASTER.png` is the sole visual authority for this
screen. This specification records the approved Figma export and never
authorizes visual reconstruction from other material.

## Fixed visible composition

- The same full-height dark shell, left navigation, top context bar, and
  persistent right `DETAILS & ERKLÄRUNG` panel as the Overview.
- Central detail workspace: back affordance, `System Optimizer` title and
  subtitle, four horizontal metric cards, then search and status controls.
- The settings table occupies the main left content area with grouped section
  headers, rows, current state, recommendation, status, and row affordance.
- The right panel remains visible while the table is used and shows title,
  path, state pills, explanatory sections, evidence, recovery, and next-step
  content. Overflow is local to that panel.

## Visual constraints

- Preserve the Master’s dimensions, regions, card/panel treatment, separators,
  table selection outline, dark surfaces, typography hierarchy, and spacing.
- Use the Master’s blue only for navigation, selected/focused interaction and
  primary actions. Use status colors only as semantic status states.
- Do not create global scrolling, replacement panels, extra columns, charts,
  or unapproved visual components.
- Example rows and values in the Master are not product truth. Runtime data,
  evidence, and safety boundaries govern content and behavior.
