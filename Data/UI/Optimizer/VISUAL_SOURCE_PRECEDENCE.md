# Optimizer Visual Source Precedence

## Binding rule

**FIGMA UI MASTER = ALLEINIGE VISUELLE QUELLE.**

1. The screen-specific `*_MASTER.png` named in `MASTER_MANIFEST.json` is the
   only authority for visible UI and overlays.
2. Its matching screen specification records approved regions and boundaries;
   it may clarify but never override the MASTER PNG.
3. Technical contracts govern behavior, backend, data truth, privacy, safety,
   and allowed actions only. They do not authorize visual deviation.

## Prohibited sources

- PDFs
- old runtime screenshots or prior layouts
- all material marked `SUPERSEDED`
- unapproved design substitutes or inferred visual decisions

If the Master does not establish a visual decision, stop for human direction;
do not improvise a replacement.
