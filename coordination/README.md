# Coordination

Dieser Ordner dient als gemeinsame Übergabe- und Statusfläche zwischen den getrennten Arbeitsumgebungen des Projekts.

- `CURRENT.md` enthält den aktuellen gemeinsamen Arbeitsstand.
- `agents/` enthält die Übergaben der einzelnen Arbeitsumgebungen.
- Dauerhafte Produktentscheidungen bleiben in `docs/DECISIONS.md`.
