# Experimental Windows packaging

`tools/dev/Build-Experimental.ps1` creates the supported local **Portable Experimental** distribution from the current functional branch. It runs the full test gate unless `-SkipTests` is explicitly supplied, verifies the locked environment and uses the canonical Variant-3 compact mark for the executable/taskbar icon.

The full Variant-3 source is retained unchanged as `src/improve_yourself/assets/improve-yourself-logo-v3-full.png`. The compact PNG/ICO are deterministic technical exports of its ascending bars/final-I region, generated by `tools/dev/Prepare-BrandAssets.py`; no replacement mark is drawn.

No Setup/installer distribution is currently claimed. The repository contains no accepted Inno Setup, WiX, NSIS or MSIX contract. Adding one requires a separate installer decision covering install scope, upgrade/uninstall identity, shortcuts and signing. Until then, the portable ZIP is the only testable distribution and remains explicitly Experimental.

The Portable archive includes `EXTERNAL_TEST_CANDIDATE_README.txt` beside the
executable.
It defines the local, read-only external-smoke path and points testers to the
adjacent hash manifest. It does not introduce an installer, updater or remote
service.
